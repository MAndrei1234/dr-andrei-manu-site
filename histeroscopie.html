Histeroscopia

O metodă minim invazivă prin care cavitatea uterină poate fi examinată direct și, atunci când este necesar, tratată în cadrul aceleiași proceduri.

Indicația și tipul histeroscopiei sunt stabilite individual. Uneori procedura are doar rol diagnostic, iar în alte situații permite și tratamentul unei leziuni identificate în cavitatea uterină.

Ce este histeroscopia?

Histeroscopia este o procedură prin care interiorul uterului este vizualizat direct cu ajutorul unui instrument subțire prevăzut cu cameră, numit histeroscop.

Instrumentul este introdus prin vagin și apoi prin colul uterin, fără incizii la nivelul abdomenului. Cavitatea uterină este destinsă cu un lichid special pentru a permite examinarea pereților uterini și identificarea eventualelor leziuni.

Tipuri de histeroscopie

Histeroscopie diagnostică

Este utilizată pentru examinarea cavității uterine și pentru clarificarea unor modificări observate ecografic sau a unor simptome. Atunci când este necesar, se pot recolta biopsii țintite.

Histeroscopie operatorie

Permite tratamentul anumitor leziuni identificate în cavitatea uterină, utilizând instrumente introduse prin histeroscop.

Când poate fi recomandată?

Histeroscopia poate fi utilă pentru evaluarea sau tratamentul unor situații precum:

  • sângerări uterine anormale;
  • sângerare după menopauză;
  • polipi endometriali;
  • fibroame submucoase;
  • îngroșări sau zone suspecte ale endometrului;
  • sinechii intrauterine;
  • septuri sau alte anomalii ale cavității uterine;
  • necesitatea unei biopsii endometriale țintite;
  • anumite situații asociate infertilității sau pierderilor de sarcină, atunci când evaluarea cavității uterine este indicată.

Ce se poate trata prin histeroscopie?

În funcție de tipul și dimensiunea leziunii, în timpul unei histeroscopii operatorii pot fi îndepărtați polipi, anumite fibroame care proemină în cavitatea uterină, sinechii sau septuri. De asemenea, pot fi prelevate biopsii din zonele suspecte.

Nu orice leziune poate sau trebuie tratată histeroscopic. Alegerea tehnicii depinde de dimensiune, localizare, profunzime și de contextul clinic.

Cum se desfășoară?

Histeroscopul este introdus pe cale vaginală prin canalul cervical. Cavitatea uterină este apoi destinsă pentru a permite vizualizarea completă. Într-o procedură diagnostică medicul examinează sistematic cavitatea, iar dacă este necesară o intervenție operatorie sunt utilizate instrumente special concepute pentru tratamentul leziunii.

Țesuturile îndepărtate sau biopsiile recoltate sunt trimise, atunci când este indicat, pentru examen histopatologic.

Anestezie și internare

Pentru procedurile efectuate în blocul operator, histeroscopia se realizează de regulă sub o anestezie de scurtă durată. Alegerea anesteziei este individualizată și este discutată cu medicul anestezist.

În practica noastră, internarea este de regulă scurtă, frecvent aproximativ 24 de ore, dacă evoluția este favorabilă.

La ce să vă așteptați după histeroscopie?

După procedură puteți avea crampe ușoare sau moderate, asemănătoare celor menstruale. O sângerare vaginală redusă sau o secreție sanguinolentă pentru câteva zile poate fi normală.

Disconfortul pelvin ușor se ameliorează de regulă progresiv.
Spottingul sau sângerarea redusă pot apărea pentru câteva zile.
Utilizați absorbante externe, nu tampoane intravaginale, cât timp există sângerare sau secreții.
Reluarea activității fizice și a contactului sexual se face conform recomandărilor primite la externare și tipului procedurii efectuate.

Există riscuri?

Histeroscopia este o procedură utilizată frecvent, însă, ca orice intervenție, poate avea complicații. Acestea sunt neobișnuite și pot include sângerare, infecție, leziuni ale colului sau perforația uterină. În procedurile operatorii pot exista și riscuri specifice legate de lichidul utilizat pentru distensia cavității uterine.

Riscul concret depinde de tipul procedurii și de complexitatea cazului și va fi discutat înaintea intervenției.

Când trebuie să solicitați evaluare medicală?

Contactați medicul sau prezentați-vă pentru evaluare dacă apar:

  • sângerare vaginală abundentă;
  • febră;
  • durere pelvină severă sau care se accentuează;
  • secreție vaginală urât mirositoare;
  • vărsături persistente, amețeală importantă sau alterarea stării generale.

Rezultatul și controlul ulterior

Dacă în timpul histeroscopiei s-a recoltat țesut, acesta este trimis pentru examen histopatologic. Controlul ulterior este stabilit în funcție de tipul procedurii, rezultatul histopatologic și simptome.
